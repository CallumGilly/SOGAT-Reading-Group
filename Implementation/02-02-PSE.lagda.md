# 2.2 Pointed Set with Endofunction
Following [section 2.2](../sogat-paris.pdf#subsection.2.2)

- [PSE](#PSE)
- [Dependent PSE](#PSE-Dep)
- [PSE Section](#PSE-Sec)

## PSE
Pointed Set with Endofuncton
```agda
  record PSE : Set₁ where
      field
          N : Set
          z : N
          s : N → N
  open PSE
```
## PSE-Dep
Dependent PSE
```agda
{-
    record PSE-Dep (S : PSE) : Set₁ where
        field
            P : (S .N) → Set
            base : P (S .z)
            ind : ∀ {n} → P n → P (S .s n)
    open PSE-Dep
-}
```

## PSE-Sec
PSE Section
```agda
{-
    record PSE-Sec {S : PSE} (DS : D-PSE S) : Set₁ where
        field
            N : (n : S .N) → (DS .P n)
            z-eq : N (S .z) ≡ DS .base
            s-eq : ∀ {n} → N (S .s n) ≡  DS .ind (N n)
    open PSE-Sec
-}
```
